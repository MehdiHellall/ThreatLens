# ThreatLens logo

`threatlens-logo.png` is the shared pixel art mark for the app header, browser icon,
and project README. Keep its transparent background. The app imports the image and
Vite gives it a content hash for caching; the HTML icon uses the same asset.

Generated with the built-in ImageGen tool. Generation prompt:

```text
Use case: logo-brand
Asset type: square pixel art logo PNG for ThreatLens, an NLP spam and phishing message classifier; used at small sizes in a dark web app header, browser favicon, and README.
Primary request: a nice, very simple pixel art logo: one bold cyan shield with a small dark magnifying lens integrated inside it. Strong, memorable silhouette and minimal internal detail.
Style/medium: crisp authentic pixel art on a consistent coarse grid (like a 32 x 32 game icon enlarged with nearest-neighbor); flat solid colors, sharply stepped edges, balanced geometry.
Composition: one centered symbol, fills about 85% of a square canvas with tight even breathing room; no separate surrounding elements.
Color palette: bright cyan #67e8f9, pale cyan #cffafe accent, and near-black zinc #09090b details, matching the existing ThreatLens interface. Keep to three colors.
Scene/backdrop: genuine transparent background with alpha, no backdrop or card.
Constraints: no text or letters, no watermark, no mockup, no gradients, no glow, no shadows, no texture, no antialiasing, no tiny fussy details. The mark must read clearly at 48px and remain recognizable as a favicon. Deliver one final logo, not a sheet of options.
```
